## English

### ✨ What is English Level Test?

A complete, professional English proficiency test with **CEFR alignment** (Common European Framework of Reference for Languages). Runs as a single HTML file — no installation needed, works in any browser.

### 🧠 Test Sections

| Section | Questions | Description |
|---------|-----------|-------------|
| 📖 **Vocabulary** | 30 questions | CEFR-aligned words from A1 to C2 |
| ✏️ **Grammar** | 25 questions | Fill-in-the-blank & multiple choice |
| 🎧 **Listening** | 15 sentences | Web Speech API — listen & type |
| 📝 **Writing** | 5 prompts | Auto-evaluation with detailed feedback |

### 📊 CEFR Levels

| Level | Description |
|-------|-------------|
| **A1** | Beginner — Starting to learn |
| **A2** | Elementary — Simple sentences |
| **B1** | Intermediate — Everyday conversation |
| **B2** | Upper-Intermediate — Complex texts |
| **C1** | Advanced — Near-professional |
| **C2** | Proficient — Full mastery |

### 📈 Results

- **Circular charts** for each skill
- **Weakest/strongest** section analysis
- **Personalized improvement** suggestions
- **Test history** with date tracking

### 💾 Storage

- **localStorage** — results saved locally
- No server required
- Works offline
