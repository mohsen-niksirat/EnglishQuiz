## English

### ✨ What is English Level Test?

A complete, professional English proficiency test with **CEFR alignment** (Common European Framework of Reference for Languages). Runs as a single HTML file — no installation needed, works in any browser.

### 🎮 Two Answer Modes

| Mode | Behavior |
|------|----------|
| 🎯 **Real Test** | Answers stay hidden, auto-advance, go back & change answers, skip questions |
| 📖 **Practice** | Shows correct/wrong + explanation immediately, locks your answer, manual "Next" button, **"مرور توضیح" (Explain)** button with the full rule & usage tips |

Pick a mode when starting any section or the full test.

### 🧠 Test Sections

| Section | Questions | Description |
|---------|-----------|-------------|
| 📖 **Vocabulary** | 36 questions | CEFR words from A1 to C2 (190+ word bank) |
| ✏️ **Grammar** | 30 questions | Fill-in-the-blank & multiple choice (72-question bank) |
| 🎧 **Listening** | 20 sentences | Web Speech API — listen & type (42-sentence bank) |
| 📝 **Writing** | 6 prompts | Auto-evaluation with detailed feedback (24-prompt bank) |

### 📚 Smart Question Bank

- **No repeats across sessions** — answered questions are remembered and avoided on the next run
- **Smooth difficulty ramp** — questions progress A1 → C2 gradually, no sudden jumps
- **Verified content** — translations and grammar answers checked; ambiguous questions replaced

### ⏱ Session Timer

- Live timer at the top of every question
- Elapsed time reported in the answer review and final results
- Time per session saved in your history

### 📋 Answer Review

- After finishing, "مشاهده جواب‌ها" shows **every question on one page** with the correct answer highlighted green and your wrong pick marked red
- Works after both normal completion and early finish

### 📈 Results

- **Progress chart** — your score trend over time (SVG line chart with Persian dates)
- Circular charts for each skill · weakest/strongest analysis · personalized tips
- Test history with **time per session** and one-click **retry**

### 💾 Storage

- **localStorage** — results saved locally
- No server required · works offline

### 📱 Platforms

| Platform | Support |
|----------|---------|
| 🌐 Web | Any modern browser |
| 📱 Mobile | Responsive design |
| 💻 Desktop | Works offline |
| 📲 PWA | Installable |

### 🚀 Quick Start

1. Visit [EnglishQuiz](https://mohsen-niksirat.github.io/EnglishQuiz/)
2. Choose a section or the full test
3. Pick **Real Test** or **Practice** mode
4. Answer the questions, view your CEFR level, and review every answer

### 🔧 Requirements

- None! Just a modern browser
- Chrome, Edge, Firefox, Safari
- Windows, Mac, Linux, Android, iOS

## فارسی

### ✨ تعیین سطح انگلیسی چیه؟

یه آزمون جامع و حرفه‌ای برای تعیین سطح زبان انگلیسی بر اساس استاندارد **CEFR** (چارچوب مرجع مشترک اروپا). به صورت یک فایل HTML واحد — بدون نیاز به نصب، در هر مرورگری اجرا میشه.

### 🎮 دو حالت پاسخ‌دهی

| حالت | رفتار |
|------|-------|
| 🎯 **تست واقعی** | جواب مخفی می‌مونه + پیشروی خودکار + برگشت به عقب و تعویض جواب + رد کردن سوال |
| 📖 **تمرینی** | نمایش فوری درست/غلط با توضیح + قفل جواب + دکمه «بعدی» دستی + دکمه **«مرور توضیح»** با قاعده کامل و نکته کاربرد |

موقع شروع هر بخش یا آزمون کامل، حالت دلخواهت رو انتخاب کن.

### 🧠 بخش‌های آزمون

| بخش | تعداد سوال | توضیح |
|-----|-----------|-------|
| 📖 **واژگان** | ۳۶ سوال | کلمات CEFR از A1 تا C2 (بانک ۱۹۰+ کلمه) |
| ✏️ **گرامر** | ۳۰ سوال | جای خالی و انتخاب صحیح (بانک ۷۲ سوال) |
| 🎧 **لیسنینگ** | ۲۰ جمله | تبدیل متن به صدا — گوش بده و تایپ کن (بانک ۴۲ جمله) |
| 📝 **رایتینگ** | ۶ موضوع | ارزیابی خودکار با بازخورد جزئی (بانک ۲۴ موضوع) |

### 📚 بانک سوالات هوشمند

- **بدون تکرار بین جلسات** — سوالات جواب‌داده‌شده یادش می‌مونه و دفعه بعد سوالات جدید میاد
- **ترتیب سختی پلکانی** — سوالات آروم از A1 به C2 می‌رن، بدون پرش ناگهانی
- **محتوا بررسی‌شده** — ترجمه‌ها و جواب‌های گرامر تصحیح و سوالات مبهم جایگزین شدن

### ⏱ تایمر آزمون

- تایمر زنده بالای صفحه در همه سوالات
- گزارش زمان در مرور جواب‌ها و نتیجه نهایی
- زمان هر جلسه توی تاریخچه ذخیره میشه

### 📋 مرور جواب‌ها

- بعد از پایان، با «مشاهده جواب‌ها» **همه سوالات در یک صفحه** با جواب درست سبز و جواب غلط قرمز نمایش داده میشه
- هم بعد از پایان عادی، هم پایان زودهنگام

### 📈 نتایج

- **نمودار روند پیشرفت** در طول زمان (خطی SVG با تاریخ شمسی)
- نمودار دایره‌ای برای هر مهارت · تحلیل نقطه قوت و ضعف · پیشنهادات شخصی
- تاریخچه با **زمان هر جلسه** و دکمه یک‌کلیکی **تمرین مجدد**

### 💾 ذخیره‌سازی

- **localStorage** — نتایج محلی ذخیره میشه
- نیاز به سرور نداره · آفلاین کار می‌کنه
